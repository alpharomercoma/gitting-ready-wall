# GITting Ready class wall

Everyone from the GITting Ready workshop at FEU Tech AITS, on one page:
**https://alpharomercoma.github.io/gitting-ready-wall/**

## Add your site with a pull request

1. [Open the new file page](https://github.com/alpharomercoma/gitting-ready-wall/new/main/students?filename=YOUR-USERNAME.txt&value=Hello%20from%20FEU%20Tech!). If GitHub asks, click **Fork this repository**.
2. Change `YOUR-USERNAME` in the file name to your GitHub username. The file must stay inside `students/` and end in `.txt`.
3. Click **Commit changes**, then **Propose changes**, then **Create pull request**.

Once your pull request is merged, your photo and a link to your site appear on the wall.

Your link points to `https://YOUR-USERNAME.github.io/sample-ghp-deployment/`, so finish the website lab first.
